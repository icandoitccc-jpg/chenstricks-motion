## Q4 输出基准（V1 默认）

- 1920×1080 · 30fps · H.264
- PNG 无损中间帧 · CRF 8 · x264 preset slow · **yuv444p（4:4:4 色度）**
- 实测：8.6s 成片 ≈ 0.46MB / 450kbps，渲染 19.5s，job 墙钟 69s，峰值内存 2.4GB
- 已验证：剪映可正常导入；文字/细线/高反差边缘明显优于 4:2:0

## 使用画像（架构决策依据）

- 低频个人内容生产：每周约 1 期中长视频（10–17 分钟，上限 20），极限 2 期
- 本工具只生成**几秒～几十秒的素材片段**，成片在剪映完成
- 优先级：**免费/接近免费 → 稳定 → 本机不做重计算 → 视觉正确 → 简单好用 → 最后才是速度**
- 速度无 KPI：1 分钟很好，3–5 分钟完全没问题，10–20 分钟现阶段可接受
- 素材即用即弃：上传 → 渲染 → 下载 → 保留 24–48h → 自动删除；不建素材库/项目历史/用户系统/数据库
- 不按 SaaS/多用户/高频/并发设计，不为未来需求提前增加复杂度

## PoC 实测存档（GitHub Actions ubuntu-latest, 2 vCPU / 7.8GB）

- 链路A 图片局部动画：1080p30 9.5s/286帧，渲染 14.6s，墙钟 58s，峰值 1999MB，0.63MB
- 链路B 信息对比动画：1080p30 8.6s/258帧，渲染 15.1s，墙钟 64s，峰值 2012MB，0.31MB
- 中文渲染（打包 Noto Sans SC）无豆腐块；预览与成品同源同字体
- Actions 计费 ≈ 1 分钟/条；私有仓库 2000 分钟/月，30 条/月用量仅占 ~2%
- 报告与样片：https://icandoitccc-jpg.github.io/github-xiezuo/motion-poc/index.html

## V1 范围（不扩大）

- 功能A：图片局部区域独立动画（非整图 Ken Burns）
- 功能B：信息动画（理解信息关系，非套模板）
- 底层统一：Input Adapter → 统一 Animation Spec(JSON) → Animation Engine → Remotion → GitHub Actions → MP4
- 不做：AI 图生视频、人物眨眼/转头/说话、时间轴剪辑、TTS、字幕、素材库、用户系统、付费
